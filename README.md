Credit Scoring Application
Desktop-приложение для автоматической оценки кредитоспособности клиента. Разработано в учебных целях для отработки навыков работы с Python, Tkinter и pandas.

Функционал
Приложение позволяет ввести анкетные данные клиента: телефон, возраст, пол, семейное положение, количество детей, профессию, стаж, район проживания, зарплату, а также параметры кредита: сумму и срок.
Программа автоматически проверяет зарплату на соответствие рыночным диапазонам из справочника профессий с учётом стажа и районного коэффициента. Если зарплата выходит за пределы нормы, пользователь получает предупреждение.
На основе введённых данных рассчитывается коэффициент платёжеспособности (аналог PDI): разница между суммарным доходом и ежемесячным платежом делится на сумму нормативных расходов на детей и пенсионных отчислений заёмщика и супруга.
Процентная ставка корректируется в зависимости от стажа и района проживания по формуле: 30.0 / (районный коэффициент * коэффициент стажа * 0.8). При коэффициенте платежеспособности меньше единицы клиент признаётся некредитоспособным, ему автоматически предлагается ограниченный кредит до 250 000 рублей с подбором срока для достижения приемлемого коэффициента.
Если коэффициент больше единицы, клиенту предлагаются на выбор три варианта кредита: исходный, увеличенный (сумма +15%, ставка -3%) и уменьшенный (сумма -15%, ставка +3%). Для каждого варианта автоматически подбирается срок, при котором коэффициент становится не ниже единицы.
Все заполненные заявки сохраняются в Excel-файл credit_applications.xlsx с полной историей. Приложение использует справочные файлы jobs_salary.xlsx (зарплаты по профессиям), work_experience.xlsx (коэффициенты стажа) и place_of_work.xlsx (районные коэффициенты).

Технологии
Python 3.9+, Tkinter, pandas, openpyxl, re, datetime.

Установка и запуск
Установите зависимости командой: pip install pandas openpyxl. Затем запустите файл var2.py: python var2.py. При первом запуске все необходимые Excel-файлы создаются автоматически, если их нет в папке с проектом.
