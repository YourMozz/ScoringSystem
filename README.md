# ScoringSystem
Десктопное приложение на Python/Tkinter для оценки кредитоспособности. Рассчитывает коэффициент платёжеспособности с учётом дохода, детей и пенсионных взносов. Валидирует зарплату по справочнику профессий с поправкой на стаж и район. Генерирует три варианта кредита. Сохраняет заявки в Excel.
